# demo_workspace — 心理 / 教育工作台(练习靶子)

> 这是给 s0–s7 用的**练习靶子**。为什么给你一个"假工作台"?
> 因为 agent 的记忆、工具、技能这些机制,**只有在真实场景里才看得出价值**——
> 光问"1+1"看不出记忆有啥用,光"创建 hello.txt"看不出技能有啥用。
> 这个工作台模拟一个**心理/教育助教**每天面对的东西:学生作文、来访者日记、一堆待办。
> s0–s7 的每个"复杂例子"和作业,都在这上面跑。

## 里面有什么

```
demo_workspace/
├── 作文/
│   ├── 小明_我的暑假.txt        # 一篇学生作文(给"作文反馈"技能 + s3 文件任务)
│   └── 小红_一次科学实验.txt     # 另一篇(可做批量任务:哪篇更需要修改?)
├── 心情日记.txt                # 一段有情绪困扰的日记(给"倾听 / CBT"技能语境)
└── 待办清单.md                 # 几条待办(给 s3 练文件操作)
```

## 怎么用它(例)

- **s3(会动手的 agent)**:"读 `demo_workspace/作文` 里所有作文,告诉我哪篇最需要修改"
- **s5(换技能)**:把技能换成 `skill_feedback.md`,给 `小明_我的暑假.txt` 写一份鼓励式评语
- **s7(多技能)**:用倾听 + CBT 组合,回应 `心情日记.txt` 里的情绪困扰

> 纯玩具内容,无任何真实隐私。做作业时建议**复制一份**再改,别改坏原件。
